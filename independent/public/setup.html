ORIGINAL M5STACK CARDPUTER

Give your Cardputer a voice.

Install once. Choose Wi-Fi and enter your provider key on the Cardputer. Start talking.

1

Install through USB

Plug your Cardputer into a computer and open this page in Chrome or Edge. Choose the Cardputer’s USB serial port when prompted.

For USB installation, open this page in Chrome or Edge on a computer. Open this page over HTTPS to install through USB.

Installation replaces the current firmware, including Launcher. Keep the erase option off to preserve saved settings. Tap the Cardputer’s Reset button after installation if it does not start.

Download app binary · Checksums · Build instructions and licenses

2

Choose Wi-Fi on the Cardputer

Select your 2.4 GHz network and enter its password using the keyboard. Existing saved Wi-Fi can be kept.

Use the arrow keys (Fn + ; / .) and Enter. Tab opens manual network entry. The Cardputer connects and saves a working password automatically.

3

Choose your voice provider

Enter that provider’s API key on the Cardputer. The key is saved on the device and used by the voice bridge during your connection. It is not saved in our database.

Gemini — start with a free voice

Create a key in Google AI Studio. Keep the Google project on the Free tier with billing off, then choose Gemini and enter the key on the Cardputer. No Agent ID is needed.

Google’s Live API uses preset voices. Free access depends on your project’s current quota.

ElevenLabs — use your existing cloned-voice agent

In ElevenLabs Agents, choose an agent configured with your voice or clone, personality, and first greeting. Enter its API key and Agent ID on the Cardputer.

The agent needs PCM 16 kHz input, PCM output, and agent_response_complete enabled in its client events. Cloning and conversations follow your ElevenLabs plan.

Hume — use your existing voice configuration

Choose a configuration in Hume with your desired voice and personality. Enter your Hume API key and Config ID on the Cardputer. Voice access and usage follow your Hume plan.

Wait for the greeting. Then talk.

Your settings are remembered. Hold Fn + W for two seconds to change Wi-Fi, provider, or key later.

The shared bridge currently allows 10 minutes per provider key per UTC day, with 20 minutes shared across visitors and two simultaneous conversations. Sessions reconnect within four minutes. Provider limits also apply. Visitor chats are not stored, and reconnects start a new visitor conversation.
